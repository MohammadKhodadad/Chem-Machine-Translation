# Zoomed API Cost, Mixed Rank and Latency

Native API cost and mixed-rank coordinates are unchanged. Each panel uses its own padded observed cost/rank range without clipping points. Latency bubble areas keep the original common scale: 8 square points per second. Axes are not shared across panels; compare tick values, not visual distances between figures.

Prices are hypothetical hosted-API reference repricing of original token workloads, not actual bills. Timings are from original local/API deployments, not the quoted hosted service. Workloads, hardware and concurrency differ; rows are not proven matched to quality evaluation. Unpriced models are omitted, not costed at zero. Ranks remain among all selected models, not reranked within priced models.
