# Language-Based Zoomed Native Violins

X = language, dots = models, paired violins = zero-shot/few-shot. For each model, language and prompt, first average supported partner directions equally. Each violin contains one such mean per model, not one point per direction. The median line summarizes model means. Constant or fewer than three scores use points and a median line without a density estimate. Shared direction support requires all models and both prompts; partner sets can differ across languages and metrics. Both prompts share a padded native-score axis within each panel; panels zoom independently, without normalization, log transforms or clipping. General scores are shared; terminology uses Luna llm_enriched only. Counts and direction lists are exported; equal counts do not prove matched rows. Descriptive only.
