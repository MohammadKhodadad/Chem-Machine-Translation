# Individual-Model Direction Performance

One figure per model, dataset and prompt. Rows are source languages; columns are target languages. Four native metrics: COMET, chrF++, variant-aware coverage (%) and term BERTScore recall. Terminology uses Luna LLM-enriched terms only. These are direction aggregates, not individual translations or model summaries. Each metric requires every selected model and both prompts for a direction. Color limits are identical across models/prompts within each dataset/metric. Missing support is NA, not zero; row identities are not verified. This collection is outside Chosen.

[Native scores and scored-row counts](../../../tables/model_direction_scores.csv)

Rebuild: `uv run --no-sync python scripts/render_evaluation_results.py --model-directions-only`.
