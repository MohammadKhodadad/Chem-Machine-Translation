# Direction-Level Terminology

Variant-aware target-term coverage (%) and term BERTScore recall (native), with best/median heatmaps side by side for each annotation group. Datasets, annotation views and prompt settings remain separate. Each supported direction requires every selected model and both prompts. Different metrics/groups can have different support; NA is not zero. Best-model scores are selected on this evaluation set, not validated policies.
