\section{Examples and visualization figures}

\subsection{Full quantitative comparisons}
The main paper condenses Chosen~01 and Chosen~04. The following supplementary figures retain both
terminology annotation views, all three datasets, and both prompting settings. Family ranks and
metric-specific direction supports follow the main reporting protocol. The two entirely unavailable
terminology-success-rate metrics are omitted. All/external/refined groups are alternative scored
populations, not a matched-row annotation ablation. Chosen~02 reports observed deployment latency;
Chosen~03 reprices recorded tokens using published API quotes. Hardware, workloads, and billing
conditions are not controlled, so these are supporting diagnostics rather than efficiency estimates.
